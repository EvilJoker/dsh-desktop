## 候选筛选策略

### 第一梯队（强烈建议深读）

- `cc-haha`（14.4k★）— 国产工作台天花板
- `clawd-on-desk`（6.2k★）— Agent 桌宠的事实标准
- `token-monitor`（2.1k★）— Token 监控刚需
- `OpenPetsHQ/openpets`（1.2k★，增速猛）— 桌宠 + 插件 SDK + MCP
- `zebar`（3.1k★）— Widget 框架最佳实践
- `Fabric-Development/fabric`（1.4k★）— Python widget 框架

### 第二梯队（按方向选择）

- 本地 LLM：`MiniCPM-Desk-Pet`、`airi`、`Open-LLM-VTuber`
- Live2D：`Miru`、`Petto`、`Ark-Pets`
- macOS：`agentpet`、`Hopet`、`TermiPet`
- 同技术栈：`WolfChen1996/DesktopPet`（PyQt5）

### 第三梯队（参考架构）

- `rainmeter`（PluginAPI 设计）
- `Monit`（插件化 + Vue）
- `awesome-ai-companion`（生态地图）
