# 透明面板实现方案

## 1. 背景与目标

参考中兴自研「云电脑管家」的桌面悬浮球（带 83% 进度的圆形小球 + 可展开看板），
为本项目「桌面助手」做一个最小骨架：在云桌面上能创建**透明、无边框、置顶、可拖动**的浮层，作为后续看板的承载窗口。

本文档记录：

- 调研发现的"云电脑管家"实现技术
- 选型与关键技术点
- 穿刺脚本与验证结果

## 2. 调研结论：电脑管家是怎么做的

### 2.1 程序构成

| 进程 | 路径 | 角色 |
| ------ | ------ | ------ |
| `SysMonitorBall` | `/opt/ZTE/ZXCloud/sysguard/SysMonitorBall` | 悬浮球本体（GUI） |
| `SysGuard` | `/opt/ZTE/ZXCloud/sysguard/SysGuard` | 主面板「云电脑管家」 |
| `AssistantService` | `/opt/ZTE/ZXCloud/sysguard/AssistantService` | systemd 后台服务，采集数据 |

### 2.2 实际窗口结构（X11 实证）

```text
SMBMainWidget        37 × 75   +1883+136   <- 悬浮球本体（贴右边）
SysMonitorBall      148 × 130  +1772+178   <- 悬浮球弹出的小看板
SysGuard            880 × 580  +510 +188   <- 完整主面板
```

证据来源：`xwininfo -tree -root | grep -iE "(monitor|ball|sysguard)"`

### 2.3 技术栈

- **GUI 框架**：Qt 5（C++）
  - 证据：`ldd SysMonitorBall` → `libQt5Widgets.so.5 / libQt5Gui.so.5 / libQt5Core.so.5 / libQt5Network.so.5 / libQt5Sql.so.5`
- **窗口属性**（来自 `strings SysMonitorBall`）：
  - `Qt::FramelessWindowHint`（无边框）
  - `Qt::WA_TranslucentBackground`（透明背景）
  - `Qt::WindowStaysOnTopHint`（置顶）
  - `Qt::Tool` + `WA_X11NetWmWindowTypeToolTip`（不进任务栏）
  - `setMask()`（异形/圆形窗口）
- **样式**：QSS 皮肤系统（`:/images/skin/deepblack`、`:/images/skin/brightwhite`）
- **进程间通信**：
  - 悬浮球 ↔ 主面板：`QLocalSocket`（Unix Local Socket）
  - 后台服务：UDP `46884`（来自 `config/SysGuard.ini` 的 `[Assistance] udpport=46884`）

## 3. 选型决策

| 候选方案 | 适用性 | 选择 |
| ---------- | -------- | ------ |
| **PyQt5** | 系统已预装(`/usr/bin/python3` + `/usr/lib64/python3.6/site-packages/PyQt5` 5.13.1)，无需安装；与电脑管家同栈，问题可对照排查 | ✅ 采纳 |
| Qt5 + C++ | 与电脑管家完全同构，但开发慢、需配编译链 | ❌ 过重 |
| Electron / Tauri | 跨平台但需打包 Chromium，且 NewStartOS 定制 X11 上透明窗口偶有兼容问题 | ❌ 暂不用 |
| Tkinter | 透明/异形/置顶支持差 | ❌ 不满足 |

**结论**：用系统自带的 `/usr/bin/python3` + `PyQt5`，零安装、零依赖、与目标平台一致。

## 4. 核心技术点（含代码片段）

### 4.1 三个必需的窗口标志

```python
self.setWindowFlags(
    QtCore.Qt.FramelessWindowHint     # 无边框，去掉标题栏
    | QtCore.Qt.WindowStaysOnTopHint  # 始终置顶
    | QtCore.Qt.Tool                  # 不在任务栏出现
)
```

### 4.2 透明背景（关键属性）

```python
self.setAttribute(QtCore.Qt.WA_TranslucentBackground, True)
```

只有同时设置 `FramelessWindowHint` 和 `WA_TranslucentBackground`，背景才能真正透明，否则会看到默认灰色底。

### 4.3 自绘圆角/异形

透明背景下，**控件不再绘制系统背景**，必须自己在 `paintEvent` 里画：

```python
def paintEvent(self, _event):
    painter = QtGui.QPainter(self)
    painter.setRenderHint(QtGui.QPainter.Antialiasing)  # 抗锯齿圆角必备
    painter.setPen(QtCore.Qt.NoPen)
    painter.setBrush(QtGui.QColor(30, 30, 40, 200))     # 第4个参数 = 透明度
    painter.drawRoundedRect(self.rect(), 14, 14)
```

要做成正圆悬浮球，把 `drawRoundedRect` 改成 `drawEllipse`，或者用 `setMask(QRegion(..., QRegion.Ellipse))`。

### 4.4 无边框窗口的拖动

系统不会再帮你处理标题栏拖动，得自己实现：

```python
def mousePressEvent(self, event):
    if event.button() == QtCore.Qt.LeftButton:
        self._drag_offset = event.globalPos() - self.frameGeometry().topLeft()

def mouseMoveEvent(self, event):
    if self._drag_offset and event.buttons() & QtCore.Qt.LeftButton:
        self.move(event.globalPos() - self._drag_offset)
```

### 4.5 X11 环境变量

云桌面下需要显式指定 DISPLAY，否则报 `cannot connect to X server`：

```bash
DISPLAY=:0 /usr/bin/python3 floatpanel_spike.py
```

### 6.1 关键命令

```bash
# 找悬浮球进程
ps -ef | grep -iE "(SysMonitor|sysguard)"

# 看窗口结构（关键！X11 实证）

# 看二进制依赖的 Qt 模块

# 看二进制里用了哪些 Qt 窗口标志/属性

# 看进程间通信方式
strings /opt/ZTE/ZXCloud/sysguard/SysMonitorBall | grep -iE "(LocalSocket|udp|dbus)"
```

### 6.2 关键路径

| 路径 | 内容 |
| ------ | ------ |
| `/opt/ZTE/ZXCloud/sysguard/` | 电脑管家完整安装目录 |
| `/opt/ZTE/ZXCloud/sysguard/config/SysGuard.ini` | 主配置（UDP 端口、阈值等） |
| `/opt/ZTE/ZXCloud/sysguard/images/` | 全部 PNG / GIF 资源 |
| `/usr/lib64/python3.6/site-packages/PyQt5/` | 系统预装的 PyQt5 |
| `/usr/lib64/qt5/plugins/platforms/libqxcb.so` | Qt5 X11 平台插件（关键） |

### 6.3 系统环境

```text
OS:        NewStartOS V4.4.2-ZTE (RHEL8 衍生)
Kernel:    4.19.112-2.el8.x86_64
Desktop:   Nde (NewStart Desktop Environment)
Display:   X11 (DISPLAY=:0)
Python:    /usr/bin/python3 = Python 3.6.8
PyQt5:     5.13.1
```

### 6.4 易踩的坑

1. **`/usr/local/bin/python3` 没有 PyQt5**，必须用 `/usr/bin/python3`。
2. **不设 `WA_TranslucentBackground`** 只会得到一个无边框的灰底窗口。
3. **`paintEvent` 必须自己画**，否则透明窗口里什么都看不到。
4. **拖动要自己写**，无边框窗口系统不再代劳。
5. **`DISPLAY=:0` 必须导出**，云桌面里直接跑会报连不上 X。
